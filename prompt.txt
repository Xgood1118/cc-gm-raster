在现有 raster 骨架上，把它做成一个能正确出图的软件光栅化器。保留 Vec3、Triangle、
load_scene、Framebuffer、project、rasterize_triangle、render、save_png 的现有名字与签名，
只用 Python 标准库，不得引入第三方依赖，不得改动 data/scene.txt。

## 需要完成

1. **三角形填充**
   - 三角形内部要被完整覆盖，不能只画顶点。
   - 顶点颜色按重心坐标插值到每个像素。
   - 斜边不能出现阶梯状的硬锯齿。

2. **深度关系**
   - 场景里前后重叠的三角形，离相机近的要盖住远的，与绘制顺序无关。
   - 深度值相等时的取舍要有一致的规则，并在 README 里写明。

3. **屏幕裁剪**
   - 投影落在画面外的顶点不能越界写入，也不能因此抛异常。
   - 部分越界的三角形只画画面内的那部分。

4. **朝向**
   - 背向相机的三角形不参与绘制，判定规则写进 README。

5. **出图**
   - 产出一张 PNG，尺寸与场景文件一致。
   - 同一份场景连续跑两次，输出文件逐字节相同。

6. **测试**
   - 覆盖：内部填充非空、遮挡关系正确、越界不抛异常、背面不绘制、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m raster.cli data/scene.txt --out out.png`，把画面里的像素统计
（非背景像素数、四种颜色各自的覆盖像素数）贴进 README。
