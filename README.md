# 软件光栅化器

纯 Python 标准库实现的软件光栅化器：解析场景文件，把三角形渲染成 PNG。

## 功能与规则

- **三角形填充**：按重心坐标做扫描线光栅化，三角形内部完整覆盖；
  顶点颜色按重心坐标插值到每个像素（`Triangle.color` 为单色时广播到三个顶点，
  也支持 `((r,g,b),(r,g,b),(r,g,b))` 的逐顶点颜色）。
- **抗锯齿**：以 3 倍分辨率渲染（每像素 3×3 个子像素），再盒式滤波下采样，
  斜边为平滑过渡，没有阶梯状硬锯齿。倍数见 `raster/core.py` 的 `SUPERSAMPLE`。
- **深度关系**：深度缓冲保存透视插值后的 `1/z`，值大者离相机近。
  新片元**严格大于**缓冲值才覆盖，因此离相机近的三角形盖住远的，与绘制顺序无关；
  **深度相等时保留先画的三角形**（后来的不覆盖）。
- **屏幕裁剪**：扫描线包围盒在光栅化前裁剪到帧缓冲范围内，
  画面外的像素一律不写入、不抛异常；部分越界的三角形只画画面内的部分。
- **背面剔除**：令 `n = (b - a) × (c - a)`，若 `n · (eye - a) <= 0`，
  即三角形法线背向相机（从相机看顶点为顺时针，或三角形退化、面积为零），则不绘制。
- **出图**：`save_png` 输出 8 位 RGB PNG，尺寸与场景 `size` 一致；
  文件不含时间戳等不稳定字段，同一份场景连续渲染两次输出逐字节相同。

## 运行

```
python -m raster.cli data/scene.txt --out out.png
python -m pytest tests -q
```

## 场景文件格式

```
size W H
camera ex ey ez tx ty tz ux uy uz fov
v x y z
tri i j k r g b
```

`data/scene.txt` 里有两块相交的三角形（橙、蓝）、一块更远的三角形（绿）
和一块夹在中间的小三角形（黄）。其中绿色与黄色三角形的法线背向相机，
按上面的剔除规则不参与绘制。

## 渲染结果像素统计（data/scene.txt → out.png，320×240）

- 非背景像素数：**42000**
- 橙色 (220, 90, 60)：**21480**
- 蓝色 (60, 140, 220)：**20040**
- 绿色 (90, 200, 120)：**0**（背面，被剔除）
- 黄色 (240, 220, 80)：**0**（背面，被剔除）

另有 480 个像素是三角形边缘的抗锯齿过渡色（前景色与背景的混合），
不计入上面四种纯色。蓝色三角形离相机更近（z=2），盖住了橙色三角形（z=0）
的重叠部分。

## 测试

`tests/` 覆盖：内部填充非空、遮挡关系与绘制顺序无关、深度相等取先画者、
越界不抛异常且只画画面内部分、背面不绘制、两次渲染输出逐字节一致、
PNG 尺寸与场景一致。`python -m pytest tests -q` 全部通过（11 项）。
